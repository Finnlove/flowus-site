# 智汇排版 · 公众号工具

在微信公众号后台编辑器里套用排版样式，并把文章一键采集到 GitHub。

## 安装

1. 打开 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录
4. 打开 mp.weixin.qq.com 的图文编辑页，右侧会出现「智汇排版」面板

## 前置

- 本地服务需运行：双击 `C:\Users\Administrator\.flowus-github-sync\start-service.cmd`
- 采集目标仓库：`Finnlove/wechat-articles`

## 用法

选中文字 → 点样式（正文 / 一级标题 / 金句 / 代码块 …）
「采集到 GitHub」需要先填标题。
